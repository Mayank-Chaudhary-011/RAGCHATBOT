# 3GPP RAG Chatbot — Mavenir GET Assignment

A Retrieval-Augmented Generation (RAG) chatbot built on 3GPP Telecom Standards documentation,
designed for near-zero hallucinations.

## Tech Stack
- **LLM**: NVIDIA Nemotron via OpenAI-compatible API
- **Embeddings**: BAAI/bge-small-en-v1.5 (Sentence Transformers)
- **Vector Store**: ChromaDB (persistent, local)
- **Backend**: FastAPI + Uvicorn
- **Frontend**: Vanilla HTML/CSS/JS
